# Deku Baba combat savestates (`zelda/combat/deku-baba`)

Ten Dolphin savestates of the **Deku Tree's first room** in *Ocarina of Time* (Wii VC `NACE01`, NTSC 1.2 ROM), all on File 1 "LINK" (3 heart containers, Kokiri Sword on B, Deku Shield, 0 rupees), used as episode start states for the combat PPO task (`docs/COMBAT_TASK.md`). The goal from each is to kill every live Deku Baba without dying or leaving the room. Every state also contains 3 Skullwalltulas on the walls and 3 Skulltulas on the upper floors; they are out of reach and not targets.

- **S3:** `s3://zelda-rl/zelda/combat/deku-baba/` ([console](https://us-west-1.console.aws.amazon.com/s3/buckets/zelda-rl?region=us-west-1&prefix=zelda/combat/deku-baba/)): private, SSE-AES256, versioned.
- **Manifest:** [`manifest.json`](manifest.json) (machine-readable; generated by `scripts/build_savestate_manifest.py` from game RAM).
- **Emulator:** Dolphin 2603a (state files are version-locked). Loads on macOS ARM and Linux x86.

## Use

```sh
aws s3 sync s3://zelda-rl/zelda/combat/deku-baba/states/ "$HOME/Library/Application Support/Dolphin/StateSaves/" --profile race-wm
# play the final policy from any slot
aws s3 cp s3://zelda-rl/zelda/combat/deku-baba/checkpoints/G150_deku-combat-gru-v2b_u00120.pt checkpoints/kept/ --profile race-wm
DOLPHIN_BIN=~/.cache/zelda-rl/Dolphin.app/Contents/MacOS/Dolphin .venv/bin/python-dbg scripts/play.py \
  checkpoints/kept/G150_deku-combat-gru-v2b_u00120.pt --slot 7
```

Loading: Dolphin hotkey *Load State Slot N* (the RL env sends it over the hotkey pipe).
